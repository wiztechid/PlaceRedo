# PlaceRedo

**Plan it. Price it. Redo it.**

PlaceRedo is being built as a home-project decision and cost-intelligence platform — not a collection of disconnected calculators.

## Product journey
Estimate → Decide → Optimize → Shop → Plan → Execute → Track → Learn

## Current MVP
- Foundation and responsive homepage
- Painting Project Planner v0.1
- Transparent assumptions and estimate methodology
- SEO primitives: canonical URLs, robots.txt, sitemap and WebSite schema

## Product principles
1. Useful ranges beat fake precision.
2. Every number should expose its assumptions.
3. Affiliate recommendations follow project need — never the other way around.
4. Estimate vs. actual cost is a future core data loop.
5. Engine calculates; AI explains.

## Roadmap
Painting → Flooring → Fence/Deck → Actual Cost Tracker → Local Cost Intelligence → PlaceRedo Cost Index.
